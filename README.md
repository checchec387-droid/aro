# Road Engineering Expert

Prototype autonome de plateforme professionnelle d'ingénierie routière.

## Lancer l'application
- Ouvrir `index.html` dans un navigateur récent.
- Aucune installation ni connexion Internet n'est nécessaire.

## Fonctionnalités incluses
- Tableau de bord et gestion locale des projets
- Bibliothèque multi-référentiels (ARP, ICTAAL et ajout manuel)
- Import local de documents de référence (PDF, DOC, DOCX, TXT) et suivi du statut d'extraction/validation
- Calcul géométrique de paramètre de clothoïde A = √(R × L)
- Interpolation linéaire du dévers
- Registre des critères de conformité documentés et validés par l'utilisateur
- Historique local, export JSON et impression PDF via le navigateur
- Interface responsive en français

## Limites importantes
Cette version est un prototype front-end local. Elle ne dispose pas encore de serveur, d'authentification multi-utilisateur, d'extraction OCR/PDF automatisée, de moteur RAG, de synchronisation cloud ni de modules complets de conception CAO.
Aucun seuil réglementaire ARP ou ICTAAL n'est présumé. Les règles doivent être extraites des documents officiels, contrôlées par un expert et implémentées/testées avant toute utilisation de conformité.
